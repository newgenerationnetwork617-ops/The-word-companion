# English Bible translation library

The Word Companion is English-only and offline-first. Five complete English Bible translations are now configured for inclusion in the Android APK and first-launch local installation.

## Bundled offline editions

| ID | Display name | Abbreviation | Expected verses | Rights / handling |
|---|---|---:|---:|---|
| `kjv` | King James Version (1769) | KJV | 31,102 | Public domain outside the United Kingdom; UK Crown printing rights exception applies. |
| `asv` | American Standard Version (1901) | ASV | 31,086 | Public domain. |
| `web` | World English Bible | WEB | 31,098 | Public domain; preserve the text unchanged when using the WEB name. |
| `geneva1599` | Geneva Bible (1599) | GNV | 31,090 | Public domain, 1599 edition. |
| `webu` | World English Bible Updated | WEBU | 31,098 | Public domain; preserve the text unchanged when using the WEB Updated name. |

The four classic editions are generated by `tool/build_bundled_translations.py` from the pinned Midvash Bible Data commit `9586bd8228a747962df1ee8692730422fb7eb2ec`. Edition and rights references are retained in each package manifest. WEB Updated is generated separately by `tool/build_bundled_bible.py`.

The build scripts validate English language, the canonical 66-book Protestant order, all chapter numbers, unique verse references, non-empty verse text, expected whole-edition verse counts, and SHA-256 package checksums. The importer validates the package checksum and Scripture references again before committing each translation to local SQLite.

## Additional candidate editions

Young's Literal Translation, Darby Translation, Webster's Revision, and other demonstrably public-domain English editions can be assessed for later inclusion once complete source texts, exact editions, and redistribution terms are independently checked. The app supports importing additional properly licensed English packages.

## Copyrighted translations

Do not bundle or redistribute NIV, NKJV, ESV, NLT, NASB, or other copyrighted translations without permission from the relevant rights holder. The package importer may accept a user-provided translation package only when that package includes its own valid source and licence metadata; importing must not be presented as permission to redistribute copyrighted text.

## Package and offline requirements

- One stable package ID per translation; never overwrite another translation just because the abbreviation is similar.
- English locale only (`en` or an `en-*` locale).
- Every package records source name and URL, licence name and URL, attribution, version, and SHA-256 checksum.
- Verse references map to the canonical 66-book catalogue. Editions with a different book canon or versification need a separately designed mapping before import.
- Scripture text is bundled as APK assets and installed into SQLite on first launch. Reading, search, bookmarks, highlights, notes, and translation comparison must not require a network connection.
- WEB and WEB Updated text must remain verbatim to retain their respective names. Commentary and app-authored study notes are separate content and must never be inserted into translation text.

## Verification boundary

The source dataset provides a pinned, reproducible input and declared edition metadata. Structural validation and checksums prove package integrity and reference coverage, not a verse-by-verse critical-text comparison against every historical printed edition. The APK build and on-device first-launch/offline tests must pass before the translations can be called verified in the released app.
